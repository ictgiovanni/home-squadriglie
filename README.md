# Squadriglie Automazione · ITI Lucarelli

Home page di tutte le squadriglie: **https://www.ata-lucarelli.it**

La pagina e' generata dallo script `Siti_Squadriglie/_sorgenti/home.py` a partire dai fogli di classe. Non si modifica a mano: dopo ogni votazione dei loghi si rilancia lo script e si ricarica il contenuto di questa cartella.

Non cancellare il file `CNAME`: collega la pagina all'indirizzo.
